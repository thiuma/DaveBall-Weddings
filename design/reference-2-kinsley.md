# Reference 2 — "Kinsley Prep" (layout-only block catalog)

Source: the two selected frames in the Paper file `daveball-weddings`, both full captures of a
tutoring-company website template.
- **Frame C**: home page, 1617 × 8042, the leftmost frame on the canvas
- **Frame D**: inner page, 1617 × 5163, the second frame from the left

**This is a layout reference only.** Its UI styling, colours, fonts, icons and copy are ignored.
Each block below gets a code (K1, K2, …) so it can be referred to and adapted to our concept:
our brand tokens, content from `content/content.md`, and photos only from Drive.

---

## Shared layout traits

- **Left-aligned, editorial.** Unlike reference 1, which is centred, almost everything here hangs off a
  strong left edge (~33px gutter at 1617px). Headlines run wide (up to ~95% of the width).
- **Asymmetric splits.** Most sections pair a big left headline with small text pushed far right,
  leaving an empty middle.
- **Hairline rules** (1px) split headline rows from supporting text and close off cards.
- **Pill eyebrow labels**: a small outlined capsule above a section headline.
- **Generous vertical space**: ~110px above eyebrows, and ~150px+ between sections.
- **Backgrounds**: a single tinted ground for most sections, broken up by full-colour bands (hero,
  colour panel, stats band, footer).

## Compared with reference 1

- Reference 1 (L-blocks) is **centred and romantic**: arches, ornaments, centred statements.
- Reference 2 (K-blocks) is **left-aligned and editorial**: hairlines, pill labels, asymmetric splits,
  structured cards.
- They mix well. For example, a K2 hero, K4 statement, K6 about, K3 or K5 services, K8 price figures,
  K14 testimonial, then a K9 contact split and K10 footer, plus L-blocks such as the arch portrait (L4)
  or a photo slideshow (L6) where some softness is wanted.
